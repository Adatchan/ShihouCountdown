# 司法試験カウントダウン (ShihouCountdown)

macOS のメニューバーに司法試験までの残日数を表示する常駐アプリです。

```
メニューバー:  残358日
```

## 特徴

- **日程の自動推定** — 司法試験は「海の日(7月第3月曜)で三連休になる週の日曜日」が最終日、その4日前の水曜日が初日という法則から、毎年の日程を自動計算します。手動設定は不要です
  - 例: 2025年 → 初日 7/16・最終日 7/20 / 2026年 → 初日 7/15・最終日 7/19
- **自動繰り越し** — 試験最終日が過ぎると、翌日から自動的に翌年の推定日程へのカウントに切り替わります
- **手動オーバーライド** — 公式日程が推定とズレた年はメニューから日付を手動指定できます。その試験が終わると自動推定に復帰します
- **試験期間中の表示** — 試験期間の5日間は赤字で「試験中」と表示
- **直前期の色分け** — 残100日以内はオレンジ、残30日以内は赤
- **表示形式の切替** — `残n日` / `D-n` / `数字のみ` から選択
- **節目の通知** — 残100・50・30・7・1日に macOS 通知。試験期間中は毎朝応援通知
- **進捗バー** — メニュー内に `■■■■■■■□□□ 70%` のような進捗表示
- **正確な自動更新** — 0時ちょうど・スリープ復帰時に即時更新

## 必要環境

- macOS 13 以降 (Apple Silicon / Intel)
- ビルドに Swift ツールチェーン (Xcode Command Line Tools: `xcode-select --install`)

## インストール

```sh
git clone https://github.com/Adatchan/ShihouCountdown.git ~/ShihouCountdown
~/ShihouCountdown/build.sh
open ~/Applications/ShihouCountdown.app
```

### ログイン時に自動起動する場合

`launchagent/com.yuki.shihoucountdown.plist` 内の `USERNAME` を自分のユーザー名に置き換えて:

```sh
cp launchagent/com.yuki.shihoucountdown.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.yuki.shihoucountdown.plist
```

## 使い方

メニューバーの「残n日」をクリックすると:

```
司法試験まで残り 358 日
試験1日目: 2027/07/14（自動推定）
□□□□□□□□□□ 0%（経過 1/359 日）
────────────────
試験日を手動設定…
自動推定に戻す
設定ファイルを編集
再読み込み
────────────────
表示形式         ▸  残n日 / D-n / 数字のみ
────────────────
終了
```

### 試験日の設定 (`exam-date.txt`)

```
# "auto" = 海の日(7月第3月曜)から自動推定 / YYYY-MM-DD = 初日を手動指定
auto
```

`auto` の代わりに `2027-07-14` のような日付を書くと手動指定になります。ファイル保存は即時反映されます。

## 日程推定のロジック

1. 海の日 = 7月の第3月曜日
2. 最終日 = 海の日の前日の日曜日
3. 初日 = 最終日の4日前の水曜日 (試験期間は水・木・[金休み]・土・日の5日間)
4. 今日が今年の最終日以前なら今年、過ぎていれば翌年の日程を対象にする

祝日の特例移動(五輪年など)には追従できないため、その場合は手動指定を使ってください。

## 再ビルド

```sh
~/ShihouCountdown/build.sh
```

`~/Applications/ShihouCountdown.app` に出力され、ad-hoc 署名されます。
